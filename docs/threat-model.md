# 脅威モデル

## 保護対象

- 酒蔵・協力先との信頼
- 掲載情報の完全性と出典追跡性
- 未公開の商談・取材・連絡先
- GitHub PagesとActionsの供給網

## 主な脅威と対策

| 脅威                           | 影響                 | 対策                                                |
| ------------------------------ | -------------------- | --------------------------------------------------- |
| AIがもっともらしい酒情報を生成 | 信用・関係毀損       | 出典必須、draft既定、人のレビュー                   |
| 公開GitHubへ商談情報を保存     | 個人・営業情報漏えい | 作業ツリーへ持ち込まない、禁止パス、レビュー        |
| 許諾のない画像・ロゴ           | 権利侵害             | `granted` 以外はビルド拒否                          |
| 古い商品・イベント情報         | 誤案内               | 確認日、次回確認日、週次検査                        |
| 外部Pull Requestの任意コード   | Actions秘密情報侵害  | `pull_request_target`不使用、最小権限、秘密情報なし |
| 依存Actionの改ざん             | ビルド・配布物侵害   | 完全長commit SHA固定、Dependabot、CodeQL            |
| fixtureの本番表示              | 架空実績の誤認       | `draft`を本番・RSS・サイトマップから除外            |

## 残存リスク

GitHub Pagesでは任意のCSP等をレスポンスヘッダーとして設定できません。初期サイトは外部スクリプト、分析、Cookie、ユーザー入力を持たない静的HTMLとして、攻撃面を小さくします。
