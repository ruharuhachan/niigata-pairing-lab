# コンテンツポリシー

## 原則

1. 事実、当事者発言、運営者の観察、仮説を区別する
2. 重要な事実へフィールド単位で出典を紐づける
3. 引用は必要最小限とし、元資料を複製しない
4. 写真・ロゴ・発言は、権利者、範囲、許諾日を確認する
5. AI出力は下書きに限り、人が出典と表現を確認する
6. 訂正履歴を隠さず、重要な変更をページへ残す

## 公開しない情報

- 個人の連絡先、生アンケート、録音、名刺
- 未公開の商談、契約、見積、売上、顧客情報
- 許諾のない写真、ロゴ、インタビュー
- 出典のない断定、架空の実績、推薦コメント
- 飲酒や健康に関する個別助言

## fixture

fixtureはファイル名と表示名で架空・テスト専用と分かるようにし、`claimStatus: draft` を必須とします。本番ビルド、RSS、サイトマップ、公開件数から除外します。
